- Déplacement de « Signaler un problème » vers un pied de page fixe en bas de la barre latérale, pour ouvrir la page de création d’issue GitHub depuis n’importe quel espace de travail.
- Une icône de signalement reste disponible lorsque la barre latérale est repliée. La liste des espaces de travail défile indépendamment pour que le lien reste visible.
