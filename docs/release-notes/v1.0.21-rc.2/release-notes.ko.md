# CodexPoolManager v1.0.21-rc.2

출시일: 2026-10-19

## 수정 사항

- 세션 폴더를 검색하기 전에 심볼릭 링크를 확인하여, 외장 드라이브나 연결된 폴더의 Codex 기록 사용량이 0으로 표시되는 문제를 수정했습니다.
- sessions와 archived_sessions가 같은 위치를 가리키면 실제 폴더를 한 번만 검색하여 중복 처리와 조기 읽기 제한을 방지합니다.
- rc.1의 워크스페이스 로그인 정보 수정 및 “기업” 배지를 유지합니다.

## 사전 출시 안내

- 큰 기록은 기존 읽기 제한에 도달할 수 있습니다. 이 경우 통계가 불완전하다는 안내를 계속 표시합니다.
