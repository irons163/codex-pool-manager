# CodexPoolManager v1.0.21-rc.2

リリース日：2026-10-19

## 修正

- セッションフォルダの走査前にシンボリックリンクを解決し、外付けドライブやリンク先のフォルダにある Codex 記録の使用量が 0 と表示される問題を修正しました。
- sessions と archived_sessions が同じ場所を指す場合は実際のフォルダを一度だけ走査し、重複処理と読み取り上限への早期到達を防ぎます。
- rc.1 のワークスペースのログイン情報の修正と「企業」バッジを引き継いでいます。

## プレリリースについて

- 大きな記録は既存の読み取り上限に達する場合があります。その際は統計が不完全であることを明示します。
