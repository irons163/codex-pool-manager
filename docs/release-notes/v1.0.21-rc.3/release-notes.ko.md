# CodexPoolManager v1.0.21-rc.3

출시일: 2026-10-19

## 수정 사항

- 같은 기업 워크스페이스에 여러 구성원이 있거나 이전 기록에 로그인 정보가 섞여 있어도 실제 선택한 계정 카드만 현재 계정으로 강조합니다.
- 로컬 로그인 정보 복구, 가져오기, 갱신, 전환 및 저장 시 워크스페이스와 사용자 신원을 함께 확인합니다.
- 다른 구성원의 캐시된 로그인 정보 사용을 차단하고 사용자 불일치를 명확히 표시합니다. 다시 로그인하면 해당 구성원의 기록만 갱신합니다.
- 기업 배지 및 세션 폴더의 심볼릭 링크 수정 사항을 유지합니다.

## 사전 출시 안내

- 이전 버전에서 다른 구성원의 로그인 정보가 할당된 계정은 업데이트 후 다시 로그인해 주세요.
