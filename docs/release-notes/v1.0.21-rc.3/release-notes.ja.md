# CodexPoolManager v1.0.21-rc.3

リリース日：2026-10-19

## 修正

- 同じ企業ワークスペースの複数メンバーや、以前にログイン情報が混在した記録があっても、実際に選択したアカウントカードだけを現在のアカウントとして強調します。
- ローカル情報の復元、インポート、更新、切り替え、保存時に、ワークスペースとユーザーの両方を確認します。
- 別メンバーのキャッシュ済みログイン情報の利用を防ぎ、不一致を明示します。再ログイン時は対応するメンバーの記録だけを更新します。
- 企業バッジとセッションフォルダのシンボリックリンク対応を引き継いでいます。

## プレリリースについて

- 以前の版で別メンバーのログイン情報が設定されたアカウントは、更新後に再ログインしてください。
