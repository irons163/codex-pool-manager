# CodexPoolManager v1.0.21-rc.3

Fecha de publicación: 2026-10-19

## Correcciones

- Resalta únicamente la tarjeta del miembro seleccionado, aunque varios miembros compartan un espacio empresarial o existan registros antiguos con credenciales copiadas.
- Comprueba el espacio de trabajo y la identidad del usuario al recuperar, importar, renovar, cambiar y guardar credenciales.
- Rechaza las credenciales en caché de otro miembro y muestra claramente la diferencia de usuario. Un nuevo inicio de sesión actualiza al miembro correspondiente.
- Conserva las etiquetas Empresa y las correcciones de carpetas de sesiones enlazadas.

## Nota de versión preliminar

- Si una versión anterior asignó credenciales de otro miembro a una cuenta, vuelve a iniciar sesión en la cuenta afectada después de actualizar.
