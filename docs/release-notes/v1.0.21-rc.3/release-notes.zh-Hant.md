# CodexPoolManager v1.0.21-rc.3

發布日期：2026-10-19

## 修正

- 藍框僅標示實際選中的帳號，即使同企業有多位成員，或舊紀錄曾混用憑證，也只會標示一張卡片。
- 本機憑證回收、匯入、刷新、切換與即時保存，同時比對工作區及使用者身分。
- 阻止使用另一位成員的快取憑證，並對受影響紀錄顯示明確的使用者不符提示；重新登入時會更新對應成員，不會覆蓋同工作區的其他帳號。
- 保留先前版本的「企業」標籤與 session 符號連結掃描修正。

## Prerelease 說明

- 若先前預發佈版曾將另一位成員的憑證填入帳號，請更新後重新登入受影響的帳號。
