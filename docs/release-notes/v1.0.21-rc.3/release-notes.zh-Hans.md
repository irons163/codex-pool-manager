# CodexPoolManager v1.0.21-rc.3

发布日期：2026-10-19

## 修正

- 蓝框仅标示实际选中的账号，即使同一企业有多位成员，或旧记录曾混用凭据，也只会标示一张卡片。
- 本机凭据恢复、导入、刷新、切换和即时保存，同时核对工作区及用户身份。
- 阻止使用另一位成员的缓存凭据，并对受影响记录显示明确的用户不符提示；重新登录时会更新对应成员，不会覆盖同工作区的其他账号。
- 保留之前版本的“企业”标签和 session 符号链接扫描修正。

## Prerelease 说明

- 如果之前的预发布版曾将另一位成员的凭据填入账号，请更新后重新登录受影响的账号。
