# CodexPoolManager v1.0.21-rc.7

Fecha de publicación: 2026-10-19

## Mejoras

- Elige GitHub o correo electrónico desde «Informar de un problema», al pie de la barra lateral.
- Envía informes a `feedback@codexpool.zero2codex.dev` desde la aplicación, sin abrir un cliente de correo. La dirección de respuesta es opcional.
- Las versiones de la aplicación y del sistema solo se adjuntan si se selecciona la opción. No se adjuntan automáticamente credenciales ni conversaciones.
- Se muestran los errores de envío y se evitan los duplicados al reintentar un informe sin cambios.
