# CodexPoolManager v1.0.21-rc.7

출시일: 2026-10-19

## 개선

- 사이드바 하단의 ‘문제 신고’에서 GitHub 또는 이메일을 선택할 수 있습니다.
- 메일 앱을 열지 않고 앱에서 바로 `feedback@codexpool.zero2codex.dev`로 신고할 수 있습니다. 답장 받을 이메일은 선택 사항입니다.
- 앱과 시스템 버전은 선택한 경우에만 첨부합니다. 계정 인증 정보나 대화 내용은 자동으로 첨부하지 않습니다.
- 전송 오류를 표시하고 같은 내용을 다시 시도할 때 중복 전송을 방지합니다.
