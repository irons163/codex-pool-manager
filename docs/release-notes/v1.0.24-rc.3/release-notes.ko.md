# CodexPoolManager v1.0.24-rc.3

릴리스 날짜: 2026-11-05

## 새 기능

- "지정 순서" 전환 모드를 추가했습니다. 실행 전략 페이지에서 계정 순서를 조정하고, 그 순서대로 순환 전환합니다(마지막 다음은 처음으로 돌아감).
- 지정 순서 모드에도 전환 임계값이 적용되며, 동기화 제외 및 Relay 계정은 자동으로 건너뜁니다.

## 개선

- 잔여량 정렬에서 만료되었거나 사용량 동기화에서 제외된 계정이 정상 계정 아래로 내려가며, 현재 계정은 계속 맨 위에 표시됩니다.
- 비즈니스 계정에 보라색 배지를 사용해 개인 계정과 구분합니다.
- “전환 순서” 목록에서 드래그 앤 드롭으로 순서를 변경할 수 있습니다. 위/아래 버튼도 계속 사용할 수 있습니다.

## 수정

- 자격 증명 해지와 기타 동기화 오류를 구분하고, 토큰 교체 후 자동으로 복구합니다.
- EdDSA 공개 키를 앱에 포함하고 릴리스 아카이브에 서명하여 Sparkle 업데이트 검증을 수정했습니다.

## 제거

- `OpenAI Reset Alert` 워크스페이스와 관련 알림, 모니터링 상태, 설정을 제거했습니다.

## 참고

- Sparkle 공개 키가 포함되기 전 빌드는 이 버전을 한 번 수동으로 설치해야 합니다. 이후 업데이트는 자동으로 검증됩니다.
