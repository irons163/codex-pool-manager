# CodexPoolManager v1.0.24-rc.4

發布日期：2026-11-05

## 新功能

- 新增「指定順序」切換模式：可在執行策略頁調整帳號順序，並依該順序循環切換，最後一個之後回到第一個。
- 指定順序模式同樣套用切換門檻，且會自動跳過已排除同步與 Relay 帳號。

## 改進

- 剩餘量排序時，已過期或已排除同步的帳號會沉到健康帳號之後，目前帳號仍維持第一。
- 商業帳號改用紫色標籤，與個人帳號區分。
- 「切換順序」清單現在支援拖曳排序，上/下按鈕仍保留供微調。
- 「切換順序」預設改依實際可切換剩餘量排序：健康帳號排在耗盡帳號前面，已排除同步的帳號維持最後。
- 順序列現在會顯示方案與工作區（個人／組織），可區分共用同一 email 的不同帳號。

## 修正

- 區分憑證撤銷與其他同步錯誤，並在權杖輪替後自動恢復。
- 修正 Sparkle 更新驗證：內嵌 EdDSA 公鑰並為發行檔案加上簽章。

## 移除

- 移除 `OpenAI Reset Alert` 工作區，以及其通知、監測狀態與相關設定。

## 注意

- 在此版本之前建置、尚未內嵌 Sparkle 公鑰的版本，需要先手動安裝此版本一次；之後的更新即可自動驗證。
