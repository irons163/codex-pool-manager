# CodexPoolManager v1.0.20-rc.5

Fecha de publicación: 2026-10-04

## Cambios

- Se establece el tamaño nativo del icono de la barra de menús en 18 × 18 puntos, sin depender únicamente del escalado de SwiftUI, y se conserva el texto completo del uso.
- Si no se puede cargar el recurso del icono, se utiliza un símbolo del sistema como alternativa.

## Nota de prerelease

- Esta es una posible corrección para el icono ausente en rc.4. Todavía hay que verificar su visibilidad en los Mac afectados.
