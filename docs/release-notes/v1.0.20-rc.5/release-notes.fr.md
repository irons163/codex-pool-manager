# CodexPoolManager v1.0.20-rc.5

Date de publication : 2026-10-04

## Modifications

- La taille native de l’icône de la barre des menus est fixée à 18 × 18 points, sans dépendre uniquement de la mise à l’échelle SwiftUI. Le texte complet de l’utilisation est conservé.
- Un symbole système est utilisé si la ressource de l’icône ne peut pas être chargée.

## Note de préversion

- Cette version propose une correction de l’icône absente dans rc.4. Son affichage doit encore être vérifié sur les Mac concernés.
