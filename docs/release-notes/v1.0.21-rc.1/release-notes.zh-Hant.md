# CodexPoolManager v1.0.21-rc.1

發布日期：2026-10-19

## 調整

- 依工作區帳號 ID 分離相同 email 的個人與企業帳號，避免僅因 email 相同而混用登入資訊。
- 同步用量時先驗證較新的本機 Codex 登入資訊，再更新帳號池；後續同步失敗或取消時，仍會保留已驗證的登入資訊。
- 登入資訊屬於另一個工作區時，停止同步與切換並顯示明確提示；刷新登入資訊時也會驗證工作區身分。
- Team、Business、Enterprise 帳號在帳號卡片、選單列與排程顯示「企業」標籤。
- 新增本機 Codex session 用量分析，提供 Token 用量、快取命中率、估算費用、趨勢、活躍度與模型／請求明細。

## Prerelease 說明

- 此預發佈版用於正式版 v1.0.21 前驗證工作區分離與企業帳號標籤；已被撤銷的登入資訊仍需重新登入。
