# CodexPoolManager v1.0.21-rc.1

リリース日：2026-10-19

## 変更点

- 同じメールアドレスを使用する個人用と企業用のワークスペースをアカウント ID で区別し、メールアドレスだけを理由にログイン情報を流用しないようにしました。
- 新しいローカル Codex ログイン情報を検証してからアカウントプールを更新し、その後の同期が失敗またはキャンセルされても検証済みの情報を保持します。
- ログイン情報が別のワークスペースに属する場合は同期と切り替えを停止し、再ログインを案内します。トークン更新時もワークスペースを確認します。
- Team、Business、Enterprise アカウントのカード、メニューバー、スケジュールに「企業」バッジを表示します。
- ローカル Codex セッションの分析を追加し、トークン使用量、キャッシュヒット率、推定費用、推移、アクティビティ、モデル別・リクエスト別の内訳を表示します。

## プレリリースについて

- 正式版 v1.0.21 に向けてワークスペースの区別と企業アカウントのバッジを検証する版です。失効したログイン情報は再ログインが必要です。
