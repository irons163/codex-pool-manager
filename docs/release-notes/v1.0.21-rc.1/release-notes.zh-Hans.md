# CodexPoolManager v1.0.21-rc.1

发布日期：2026-10-19

## 调整

- 按工作区账号 ID 区分使用相同 email 的个人和企业账号，避免仅凭 email 相同而混用登录信息。
- 同步用量时先验证较新的本机 Codex 登录信息，再更新账号池；后续同步失败或取消时，仍会保留已验证的登录信息。
- 登录信息属于另一个工作区时，停止同步和切换并显示明确提示；刷新登录信息时也会验证工作区身份。
- Team、Business、Enterprise 账号在账号卡片、菜单栏和排程中显示“企业”标签。
- 新增本机 Codex session 用量分析，提供 Token 用量、缓存命中率、估算费用、趋势、活跃度和模型／请求明细。

## Prerelease 说明

- 此预发布版用于正式版 v1.0.21 前验证工作区区分和企业账号标签；已被撤销的登录信息仍需重新登录。
