# CodexPoolManager v1.0.21-rc.1

출시일: 2026-10-19

## 변경 사항

- 같은 이메일을 사용하는 개인 및 기업 워크스페이스를 계정 ID로 구분하고, 이메일이 같다는 이유만으로 로그인 정보를 공유하지 않도록 했습니다.
- 더 새로운 로컬 Codex 로그인 정보를 검증한 후 계정 풀을 갱신하며, 이후 동기화가 실패하거나 취소되어도 검증된 정보를 보존합니다.
- 로그인 정보가 다른 워크스페이스에 속하면 동기화와 계정 전환을 중단하고 다시 로그인하도록 안내합니다. 토큰 갱신 시에도 워크스페이스를 확인합니다.
- Team, Business, Enterprise 계정의 카드, 메뉴 막대 및 일정에 “기업” 배지를 표시합니다.
- 로컬 Codex 세션 분석을 추가하여 토큰 사용량, 캐시 적중률, 예상 비용, 추세, 활동 내역 및 모델별·요청별 세부 정보를 제공합니다.

## 사전 출시 안내

- 정식 v1.0.21 출시 전 워크스페이스 구분과 기업 계정 배지를 검증하는 버전입니다. 폐기된 로그인 정보는 다시 로그인해야 합니다.
