# CodexPoolManager v1.0.20-rc.6

リリース日：2026-10-04

## 変更点

- メニューバーのカラーアプリアイコンを、背景が透明な単色の Codex の雲形と端末記号のアウトラインに変更しました。色はメニューバーの外観に応じてシステムが調整します。
- アイコンのネイティブサイズは 18 ポイントのままで、使用量のテキストも省略しません。
- テンプレート描画、サイズ、1×・2×・3× 解像度での透明な背景と単色の線を確認するテストを追加しました。

## プレリリースについて

- このプレリリースでは、v1.0.20 正式版の前に新しいメニューバーの外観を検証します。
