# CodexPoolManager v1.0.20-rc.6

Fecha de publicación: 2026-10-04

## Cambios

- Se sustituye el icono de color de la barra de menús por un contorno monocromático y transparente de la nube de Codex y su símbolo de terminal. El sistema adapta el color al aspecto de la barra de menús.
- Se conserva el tamaño nativo de 18 puntos y el texto completo del uso.
- Se añaden pruebas de representación como plantilla, tamaño nativo, transparencia y trazos monocromáticos a resoluciones de 1×, 2× y 3×.

## Nota de prerelease

- Esta versión preliminar valida el nuevo aspecto de la barra de menús antes de la versión estable 1.0.20.
