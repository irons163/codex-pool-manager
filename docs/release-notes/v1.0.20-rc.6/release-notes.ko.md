# CodexPoolManager v1.0.20-rc.6

출시일: 2026-10-04

## 변경 사항

- 메뉴 막대의 컬러 앱 아이콘을 투명 배경의 단색 Codex 구름 윤곽선과 터미널 기호로 변경했습니다. 시스템이 메뉴 막대 외관에 맞춰 색상을 조정합니다.
- 아이콘의 기본 크기인 18포인트와 전체 사용량 텍스트를 유지합니다.
- 템플릿 렌더링, 기본 크기, 1×·2×·3× 해상도에서의 투명 배경과 단색 선을 확인하는 테스트를 추가했습니다.

## 프리릴리스 안내

- 이 프리릴리스는 정식 v1.0.20 출시 전에 새로운 메뉴 막대 외관을 검증합니다.
