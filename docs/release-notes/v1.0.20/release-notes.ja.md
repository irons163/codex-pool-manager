# CodexPoolManager v1.0.20

リリース日：2026-10-05

この正式版には、v1.0.20-rc.1 から rc.7 までのメニューバー、ワークスペース、OAuth 更新の変更が含まれます。

## 改善

- メニューバーに、システムの外観に合わせたネイティブ 18 ポイントの単色 Codex アイコンを使用します。使用量のテキストは保持し、末尾の経過時間を削除しました。
- 起動時のメニューバー項目の表示を改善し、メニューバーダッシュボードのアカウント一覧を広げました。
- 既存のワークスペースタイトルバーをドラッグして、パネルの高さをウィンドウの 10%～90% に調整できます。選択した高さを記憶し、上下のサイズ変更カーソルを表示します。
- 設定に GitHub の問題報告へのリンクを追加しました。

## 修正

- 使用量を取得する前に更新済み OAuth 認証情報を保存し、後続のエラーやキャンセルで更新されたトークンが失われないようにしました。
- 認証情報の拒否、ネットワーク障害、レート制限、サービスエラー、refresh token の欠落を区別します。
- 遅れて完了した更新が、再インポートした認証情報を上書きしたり、削除済みアカウントを復元したりすることを防ぎます。

## 注意事項

- OpenAI Reset Alert のバッジを「まもなく削除」に変更しました。このリリースでは機能を引き続き利用できます。
- 取り消された認証情報については、再ログインが必要です。
