# CodexPoolManager v1.0.20

출시일: 2026-10-05

이번 정식 버전에는 v1.0.20-rc.1부터 rc.7까지의 메뉴 막대, 작업 공간 및 OAuth 갱신 변경 사항이 포함됩니다.

## 개선

- 시스템 외관을 따르는 네이티브 18포인트 단색 Codex 메뉴 막대 아이콘을 사용합니다. 사용량 텍스트는 유지하고 끝의 경과 시간은 제거했습니다.
- 시작 시 메뉴 막대 항목의 표시를 개선하고 메뉴 막대 대시보드의 계정 목록을 넓혔습니다.
- 기존 작업 공간 제목 막대를 드래그해 패널 높이를 창 높이의 10%부터 90%까지 조절할 수 있습니다. 선택한 높이를 기억하고 세로 크기 조절 커서를 표시합니다.
- 설정에 GitHub 문제 보고 링크를 추가했습니다.

## 수정

- 사용량을 가져오기 전에 갱신된 OAuth 인증 정보를 저장하여 이후 오류나 취소로 교체된 토큰이 유실되지 않도록 했습니다.
- 인증 정보 거부, 네트워크 장애, 요청 제한, 서비스 오류 및 refresh token 누락을 구분합니다.
- 늦게 완료된 갱신이 다시 가져온 인증 정보를 덮어쓰거나 삭제된 계정을 복원하지 못하도록 했습니다.

## 참고 사항

- OpenAI Reset Alert 배지를 “곧 제거 예정”으로 변경했습니다. 이번 버전에서는 해당 기능을 계속 사용할 수 있습니다.
- 취소된 인증 정보는 다시 로그인해야 합니다.
