# CodexPoolManager v1.0.20

發布日期：2026-10-05

此正式版整合 v1.0.20-rc.1 至 rc.7 的選單列、工作區及 OAuth 刷新調整。

## 改進

- 選單列改用原生 18 點的單色 Codex 圖示，依系統外觀顯示；保留用量文字並移除尾端經過時間。
- 改善啟動時選單列項目的顯示，並加寬選單列儀表板的帳號清單。
- 可拖曳工作區原有標題列調整面板高度，範圍為視窗高度的 10% 至 90%；記住所選高度並顯示上下調整游標。
- 在設定新增 GitHub 問題回報入口。

## 修正

- 在取得用量前先儲存刷新後的 OAuth 登入資訊，避免後續錯誤或取消時遺失已輪替的 token。
- 區分登入資訊遭拒、網路錯誤、請求限流、服務錯誤與缺少 refresh token。
- 避免延遲完成的刷新結果覆蓋重新匯入的登入資訊或還原已刪除的帳號。

## 注意事項

- OpenAI Reset Alert 標籤改為「即將移除」；此版本仍保留該功能。
- 已被撤銷的登入資訊仍需要重新登入。
