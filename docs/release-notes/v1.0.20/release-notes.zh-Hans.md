# CodexPoolManager v1.0.20

发布日期：2026-10-05

此正式版整合 v1.0.20-rc.1 至 rc.7 的菜单栏、工作区及 OAuth 刷新调整。

## 改进

- 菜单栏改用原生 18 点的单色 Codex 图标，跟随系统外观；保留用量文字并移除末尾的已过时间。
- 改善启动时菜单栏项目的显示，并加宽菜单栏仪表板的账号列表。
- 可拖动工作区原有标题栏调整面板高度，范围为窗口高度的 10% 至 90%；记住所选高度并显示上下调整光标。
- 在设置中新增 GitHub 问题反馈入口。

## 修复

- 在获取用量前先保存刷新后的 OAuth 登录信息，避免后续错误或取消时丢失已轮换的 token。
- 区分登录信息被拒、网络错误、请求限流、服务错误与缺少 refresh token。
- 避免延迟完成的刷新结果覆盖重新导入的登录信息或恢复已删除的账号。

## 注意事项

- OpenAI Reset Alert 标签改为“即将移除”；此版本仍保留该功能。
- 已被撤销的登录信息仍需要重新登录。
