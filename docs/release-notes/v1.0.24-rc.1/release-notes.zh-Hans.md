# CodexPoolManager v1.0.24-rc.1

发布日期：2026-11-05

## 新功能

- 新增“指定顺序”切换模式：可在执行策略页调整账号顺序，并按该顺序循环切换，最后一个之后回到第一个。
- 指定顺序模式同样应用切换阈值，并会自动跳过已排除同步与 Relay 账号。

## 改进

- 按剩余量排序时，已过期或已排除同步的账号会沉到健康账号之后，当前账号仍保持第一。
- 商业账号改用紫色标签，与个人账号区分。

## 修复

- 区分凭证撤销与其他同步错误，并在令牌轮换后自动恢复。

## 移除

- 移除 `OpenAI Reset Alert` 工作区及其通知、监测状态和相关设置。
