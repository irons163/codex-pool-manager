# CodexPoolManager v1.0.24-rc.1

リリース日: 2026-11-05

## 新機能

- 「指定順序」切り替えモードを追加しました。実行戦略ページでアカウントの順序を並べ替え、その順序で循環切り替えします（最後の次は先頭に戻ります）。
- 指定順序モードでも切り替えしきい値が適用され、除外中・Relay アカウントは自動的にスキップされます。

## 改善

- 残量順の並べ替えで、期限切れまたは使用量同期から除外されたアカウントが正常なアカウントの下に移動します（現在のアカウントは先頭のまま）。
- ビジネスアカウントを紫のバッジで表示し、個人アカウントと区別できるようにしました。

## 修正

- 認証情報の失効とその他の同期エラーを区別し、トークン更新後に自動復旧するようにしました。

## 削除

- `OpenAI Reset Alert` ワークスペースと、その通知・監視状態・関連設定を削除しました。
