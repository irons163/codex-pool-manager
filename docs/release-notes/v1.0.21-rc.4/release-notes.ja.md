# CodexPoolManager v1.0.21-rc.4

リリース日：2026-10-19

## 修正

- セッションログを各ファイルの 128 MiB で打ち切らず、走査開始時の末尾まで読み取り、大きな記録の後半にある使用量を復元します。
- 小さなブロックで読み取り、会話本文を早期に除外します。メタデータのバッファ上限とキャンセル機能は維持します。
- キーワードではなく実際のメタデータ型で判定し、大きなツール出力に token_count が含まれるだけで統計が不完全と誤表示される問題を修正しました。
- 企業メンバーのログイン情報の分離、企業バッジ、リンクされたセッションフォルダへの対応を引き継いでいます。

## プレリリースについて

- 読み取れないファイル、未解決の分岐元、使用量イベントの上限がある場合は、引き続き不完全な統計として表示します。
