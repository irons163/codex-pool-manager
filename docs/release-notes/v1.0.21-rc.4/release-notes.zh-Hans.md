# CodexPoolManager v1.0.21-rc.4

发布日期：2026-10-19

## 修正

- 完整读取每份 session 记录在扫描开始时的内容，不再于每个文件 128 MiB 截断，补回大型记录后半部分的用量事件。
- 以小块流式读取并提早跳过对话正文，保留元数据缓冲上限和取消功能。
- 按实际元数据类型识别用量记录，避免大型工具输出仅提到 token_count 就误报“统计不完整”。
- 保留之前版本的企业成员身份隔离、“企业”标签和 session 符号链接支持。

## Prerelease 说明

- 真正无法读取的文件、尚待确认的分支来源和用量事件数量上限，仍会显示统计不完整提示。
