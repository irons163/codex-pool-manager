# CodexPoolManager v1.0.21-rc.4

發布日期：2026-10-19

## 修正

- 完整讀取每份 session 紀錄在掃描開始時的內容，不再於每檔 128 MiB 截斷，補回大型紀錄後段的用量事件。
- 以小區塊串流讀取並提早跳過對話內文，保留中繼資料緩衝上限與取消功能。
- 依實際中繼資料類型辨識用量紀錄，避免大型工具輸出僅提到 token_count 就誤報「統計不完整」。
- 保留先前版本的企業成員身分隔離、「企業」標籤與 session 符號連結支援。

## Prerelease 說明

- 真正無法讀取的檔案、尚待確認的分岔來源與用量事件數量上限，仍會顯示統計不完整提示。
