# CodexPoolManager v1.0.21-rc.4

출시일: 2026-10-19

## 수정 사항

- 세션 로그를 파일당 128 MiB에서 중단하지 않고 검색 시작 시점의 끝까지 읽어 큰 기록 후반부의 사용량 이벤트를 복원합니다.
- 작은 블록으로 읽고 대화 본문을 미리 건너뜁니다. 메타데이터 버퍼 제한과 취소 기능은 유지합니다.
- 키워드 대신 실제 메타데이터 유형을 확인하여 큰 도구 출력에 token_count가 언급되었다는 이유만으로 불완전한 통계 경고가 표시되는 문제를 수정했습니다.
- 기업 구성원 로그인 정보 분리, 기업 배지 및 연결된 세션 폴더 지원을 유지합니다.

## 사전 출시 안내

- 읽을 수 없는 파일, 확인되지 않은 분기 원본 또는 사용량 이벤트 제한이 있는 경우에는 불완전한 통계 경고가 계속 표시됩니다.
