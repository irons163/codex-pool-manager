# CodexPoolManager v1.0.20-rc.7

リリース日：2026-10-05

## 変更点

- 使用量を取得する前に更新済みの OAuth 認証情報を保存し、その後の取得失敗やキャンセルでローテーション済みトークンが失われないようにしました。
- 認証情報の拒否、ネットワーク障害、レート制限、サービス障害、リフレッシュトークンの欠落を区別し、すべての更新失敗をログイン期限切れとして表示しないようにしました。
- 遅れて完了した更新結果が、再インポートした認証情報を上書きしたり、削除済みアカウントを復元したりすることを防ぎます。
- OpenAI Reset Alert のバッジを「まもなく削除」に変更し、すべての対応言語に反映しました。このプレリリースでは機能を引き続き利用できます。
- トークンのローテーション、エラー分類、キャンセル、古い更新結果の回帰テストを追加しました。

## プレリリースについて

- v1.0.20 正式版の前に OAuth 更新の信頼性を検証します。実際に失効した認証情報では再ログインが必要です。
