# CodexPoolManager v1.0.20-rc.7

发布日期：2026-10-05

## 调整

- 在获取用量前先保存刷新后的 OAuth 登录信息，避免后续用量查询失败或取消时丢失已轮换的 token。
- 区分登录信息确实被拒绝、网络错误、请求限流、服务错误与缺少 refresh token，不再将所有刷新失败都显示为登录信息已过期。
- 避免延迟完成的刷新结果覆盖重新导入的登录信息或恢复已删除的账号。
- 将 OpenAI Reset Alert 标签改为“即将移除”，并同步所有支持语言；此 prerelease 仍保留该功能。
- 新增 token 轮换、错误分类、取消及过时刷新结果的回归测试。

## Prerelease 说明

- 此 prerelease 用于正式版 v1.0.20 前验证 OAuth 刷新的可靠性；已被撤销的登录信息仍需要重新登录。
