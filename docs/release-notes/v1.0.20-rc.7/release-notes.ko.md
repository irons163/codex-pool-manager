# CodexPoolManager v1.0.20-rc.7

출시일: 2026-10-05

## 변경 사항

- 사용량을 조회하기 전에 갱신된 OAuth 인증 정보를 저장하여 이후 조회 실패나 취소로 교체된 토큰이 유실되지 않도록 했습니다.
- 인증 정보 거부, 네트워크 오류, 요청 제한, 서비스 오류, 갱신 토큰 누락을 구분하여 모든 갱신 실패를 로그인 만료로 표시하지 않도록 했습니다.
- 늦게 완료된 갱신 결과가 다시 가져온 인증 정보를 덮어쓰거나 삭제된 계정을 복원하지 않도록 했습니다.
- OpenAI Reset Alert 배지를 “곧 제거 예정”으로 변경하고 모든 지원 언어에 반영했습니다. 이 프리릴리스에서는 해당 기능을 계속 사용할 수 있습니다.
- 토큰 교체, 오류 분류, 취소 및 오래된 갱신 결과에 대한 회귀 테스트를 추가했습니다.

## 프리릴리스 안내

- 정식 v1.0.20 출시 전에 OAuth 갱신의 안정성을 검증합니다. 실제로 폐기된 인증 정보는 다시 로그인해야 합니다.
