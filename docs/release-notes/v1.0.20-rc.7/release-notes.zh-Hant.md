# CodexPoolManager v1.0.20-rc.7

發布日期：2026-10-05

## 調整

- 在取得用量前先儲存刷新後的 OAuth 登入資訊，避免後續用量查詢失敗或取消時遺失已輪替的 token。
- 區分登入資訊確實遭拒、網路錯誤、請求限流、服務錯誤與缺少 refresh token，不再將所有刷新失敗都顯示為登入資訊已過期。
- 避免延遲完成的刷新結果覆蓋重新匯入的登入資訊或還原已刪除的帳號。
- 將 OpenAI Reset Alert 標籤改為「即將移除」，並同步所有支援語言；此 prerelease 仍保留該功能。
- 新增 token 輪替、錯誤分類、取消及過時刷新結果的回歸測試。

## Prerelease 說明

- 此 prerelease 用於正式版 v1.0.20 前驗證 OAuth 刷新的可靠性；已被撤銷的登入資訊仍需要重新登入。
