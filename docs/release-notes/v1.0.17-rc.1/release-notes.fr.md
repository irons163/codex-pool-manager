# CodexPoolManager v1.0.17-rc.1

Date de sortie : 2026-08-06

## Corrections

- Correction de la détection des fenêtres d’utilisation Codex lorsque l’API place une limite hebdomadaire seule dans `primary_window`.
- Les cartes de compte affichent uniquement les fenêtres renvoyées par l’API et effacent les anciennes données après la synchronisation.
- L’ouverture du tableau de bord depuis la barre des menus met au premier plan la fenêtre existante au lieu d’en créer une nouvelle.

## Note de prerelease

- Cette prerelease valide la synchronisation de l’utilisation et le comportement d’une fenêtre de tableau de bord unique avant la version stable.
