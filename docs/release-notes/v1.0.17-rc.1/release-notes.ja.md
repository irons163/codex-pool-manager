# CodexPoolManager v1.0.17-rc.1

リリース日：2026-08-06

## 修正

- Codex API が週次のみの制限を `primary_window` に返す場合の使用量判定を修正しました。
- アカウントカードは API が返したウィンドウだけを表示し、同期時に古い使用量データを消去します。
- メニューバーからダッシュボードを開くと、重複ウィンドウを作らず既存のウィンドウを前面に表示します。

## Prerelease の注記

- この prerelease では、次回の正式版公開前に使用量同期と単一ダッシュボードウィンドウの動作を検証します。
