# CodexPoolManager v1.0.17-rc.1

Fecha de lanzamiento: 2026-08-06

## Correcciones

- Se corrigió la detección de ventanas de uso de Codex cuando la API coloca solo el límite semanal en `primary_window`.
- Las tarjetas de cuenta ahora muestran únicamente las ventanas devueltas por la API y eliminan los datos antiguos después de sincronizar.
- Al abrir el panel desde la barra de menús se enfoca la ventana existente en lugar de crear duplicados.

## Nota de prerelease

- Esta prerelease valida la sincronización de uso y el comportamiento de una única ventana del panel antes del lanzamiento estable.
