# CodexPoolManager v1.0.20-rc.3

リリース日：2026-09-29

## 改善

- ワークスペースの既存のタイトルバーをドラッグして、ウィンドウ高の 10%〜90% の範囲でパネルの高さを調整できます。選択した高さは保存されます。
- バーを一度クリックするとパネルを展開または折りたたみます。カーソルを重ねると上下のサイズ変更カーソルが表示されます。
- 設定に GitHub で問題を報告するためのリンクを追加しました。

## プレリリースのメモ

- この prerelease では、v1.0.20 正式版の前にパネルの高さ調整と問題報告リンクを検証します。
