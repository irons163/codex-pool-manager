# CodexPoolManager v1.0.20-rc.3

Release date: 2026-09-29

## Improvements

- Resize the workspace panel by dragging its existing header bar, from 10% to 90% of the window height. The selected size is saved.
- Click the bar once to expand or collapse the panel; hovering shows a vertical resize cursor.
- Added a Settings shortcut to report issues on GitHub.

## Prerelease Note

- This prerelease validates the adjustable workspace panel and issue-reporting entry before stable v1.0.20.
