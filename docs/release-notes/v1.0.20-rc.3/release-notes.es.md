# CodexPoolManager v1.0.20-rc.3

Fecha de publicación: 2026-09-29

## Mejoras

- Cambia la altura del panel del espacio de trabajo arrastrando su barra de título original, entre el 10 % y el 90 % de la altura de la ventana. Se recuerda el tamaño elegido.
- Haz clic una vez en la barra para expandir o contraer el panel; al pasar el cursor se muestra el indicador de ajuste vertical.
- Se añadió en Ajustes un acceso para informar de problemas en GitHub.

## Nota de prerelease

- Esta prerelease valida el panel de altura ajustable y el acceso para informar de problemas antes de la versión estable 1.0.20.
