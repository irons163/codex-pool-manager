# CodexPoolManager v1.0.20-rc.3

Date de publication : 2026-09-29

## Améliorations

- Redimensionnez le panneau de l’espace de travail en faisant glisser sa barre de titre, entre 10 % et 90 % de la hauteur de la fenêtre. La taille choisie est mémorisée.
- Cliquez une fois sur la barre pour développer ou réduire le panneau ; le survol affiche le curseur de redimensionnement vertical.
- Un raccourci dans les réglages permet désormais de signaler un problème sur GitHub.

## Note de prerelease

- Cette prerelease valide le panneau redimensionnable et l’accès au signalement de problèmes avant la version stable 1.0.20.
