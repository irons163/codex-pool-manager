# CodexPoolManager v1.0.20-rc.3

출시일: 2026-09-29

## 개선 사항

- 기존 작업 공간 제목 표시줄을 드래그해 창 높이의 10%~90% 범위에서 패널 높이를 조절할 수 있습니다. 선택한 높이는 저장됩니다.
- 표시줄을 한 번 클릭하면 패널이 펼쳐지거나 접힙니다. 커서를 올리면 위아래 크기 조절 커서가 표시됩니다.
- 설정에 GitHub 문제 신고 링크를 추가했습니다.

## 프리릴리스 안내

- 이번 prerelease는 v1.0.20 정식 출시 전에 패널 높이 조절과 문제 신고 링크를 검증합니다.
