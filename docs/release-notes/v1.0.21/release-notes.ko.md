# CodexPoolManager v1.0.21

출시일: 2026-10-19

## 개선

- Codex 로컬 사용량 분석을 추가했습니다. 토큰 수, 캐시 적중률, 예상 비용, 추세, 활동 기록과 모델별·요청별 내역을 확인할 수 있습니다.
- Team, Business, Enterprise 계정에 계정 카드, 메뉴 막대, 일정에서 Business 배지를 표시합니다.
- ‘문제 신고’를 사이드바 하단에 고정하고 GitHub 또는 앱 내 이메일을 선택할 수 있도록 했습니다. 메일 앱을 열지 않고 `feedback@codexpool.zero2codex.dev`로 전송할 수 있습니다.
- 답장 받을 이메일은 선택 사항이며, 앱과 시스템 버전은 선택한 경우에만 첨부합니다. 같은 내용을 다시 시도할 때 중복 전송을 방지합니다.

## 수정

- 같은 이메일을 사용하는 개인용·기업용 작업 공간을 분리하고, 로그인 복구, 가져오기, 인증 정보 갱신, 사용량 동기화 및 전환 시 같은 작업 공간의 서로 다른 구성원을 구분합니다.
- 현재 계정 카드는 하나만 강조 표시하고 다른 작업 공간이나 구성원의 인증 정보는 거부합니다.
- 연결된 세션 폴더를 지원하고 대화 본문을 건너뛰면서 대용량 로그 전체를 처리합니다. 누락된 사용량 이벤트와 잘못된 불완전 통계 경고를 수정했습니다.

## 업데이트 안내

- 기존 계정에 작업 공간 또는 사용자 불일치가 표시되면 해당 계정에 다시 로그인해 이전 인증 정보를 교체하세요.
