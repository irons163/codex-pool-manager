# CodexPoolManager v1.0.21

公開日：2026-10-19

## 改善

- Codex のローカル使用量分析を追加しました。トークン数、キャッシュヒット率、推定費用、推移、アクティビティ履歴、モデル別・リクエスト別の内訳を確認できます。
- Team、Business、Enterprise アカウントに、アカウントカード、メニューバー、スケジュールで Business バッジを表示します。
- 「問題を報告」をサイドバー下部に固定し、GitHub またはアプリ内メールを選択できます。メールアプリを開かずに `feedback@codexpool.zero2codex.dev` に送信できます。
- 返信先は任意で、アプリとシステムのバージョンは選択した場合のみ添付します。同じ内容の再試行による重複送信を防ぎます。

## 修正

- 同じメールアドレスを使う個人用とビジネス用のワークスペースを分離し、ログインの復元、インポート、認証情報の更新、使用量の同期、切り替え時に同じワークスペースのメンバーを区別します。
- 現在のアカウントとして強調表示するカードを一つに限定し、別のワークスペースやメンバーの認証情報を拒否します。
- リンクされたセッションフォルダーに対応し、大きなログでも会話本文を読み飛ばしながら全体を処理します。欠落していた使用量イベントと誤った不完全統計の警告を修正しました。

## 更新について

- 以前のアカウントでワークスペースやユーザーの不一致が表示される場合は、そのアカウントに再度ログインして、古い認証情報を置き換えてください。
