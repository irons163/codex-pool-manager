# CodexPoolManager v1.0.21

發布日期：2026-10-19

## 改善

- 新增 Codex 本機用量分析，提供 Token、快取命中率、估算費用、趨勢、活躍紀錄，以及模型與請求明細。
- Team、Business 與 Enterprise 帳號在帳號卡片、選單列與時間表中顯示「企業」標籤。
- 「回報問題」固定於左側欄底部，可選擇 GitHub 或 App 內寄信，直接回報至 `feedback@codexpool.zero2codex.dev`，不必開啟郵件程式。
- 回覆信箱可選填，App 與系統版本由使用者勾選後才附上；重試相同內容時避免重複寄送。

## 修正

- 分開處理同一信箱的一般與企業工作區，並在登入復原、匯入、更新憑證、同步用量與切換時區分同一工作區的不同成員。
- 只標示一張目前帳號卡片，拒絕使用其他工作區或成員的憑證。
- 支援連結至其他位置的對話目錄，完整讀取大型對話紀錄並略過對話本文，恢復遺漏的用量事件，避免誤報「統計不完整」。

## 更新提醒

- 若舊帳號仍顯示工作區或使用者不符，請重新登入該帳號，以替換先前快取的憑證。
