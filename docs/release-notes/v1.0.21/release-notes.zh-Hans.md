# CodexPoolManager v1.0.21

发布日期：2026-10-19

## 改进

- 新增 Codex 本地用量分析，提供 Token、缓存命中率、估算费用、趋势、活跃记录，以及模型与请求明细。
- Team、Business 和 Enterprise 账号在账号卡片、菜单栏与时间表中显示“企业”标签。
- “报告问题”固定在侧栏底部，可选择 GitHub 或 App 内邮件，直接发送至 `feedback@codexpool.zero2codex.dev`，无需打开邮件应用。
- 回复邮箱可选填，App 和系统版本仅在勾选后附上；重试相同内容时避免重复发送。

## 修复

- 分别处理使用相同邮箱的个人与企业工作区，并在登录恢复、导入、刷新凭据、同步用量及切换时区分同一工作区的不同成员。
- 仅将一张账号卡片标为当前账号，并拒绝使用其他工作区或成员的凭据。
- 支持链接到其他位置的会话目录，完整读取大型会话日志并跳过对话正文，恢复遗漏的用量事件，避免误报“统计不完整”。

## 更新提示

- 如果旧账号仍提示工作区或用户不匹配，请重新登录该账号，以替换此前缓存的凭据。
