# CodexPoolManager v1.0.21-rc.6

Release date: 2026-10-19

## Improvements

- Choose GitHub or email from “Report an issue” at the bottom of the sidebar.
- Send a report to `feedback@codexpool.zero2codex.dev` directly in the app, without opening a mail application. A reply address is optional.
- App and system versions are included only when selected. Reports do not automatically attach account credentials or conversation content.
- Show submission errors and prevent unchanged retries from sending duplicate reports.
