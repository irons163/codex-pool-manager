# CodexPoolManager v1.0.21-rc.6

Date de publication : 2026-10-19

## Améliorations

- Choisissez GitHub ou l’e-mail depuis « Signaler un problème », en bas de la barre latérale.
- Envoyez un signalement à `feedback@codexpool.zero2codex.dev` dans l’application, sans ouvrir de logiciel de messagerie. L’adresse de réponse est facultative.
- Les versions de l’application et du système sont jointes uniquement si l’option est cochée. Les identifiants et les conversations ne sont pas joints automatiquement.
- Les erreurs d’envoi sont affichées et une nouvelle tentative sans modification ne provoque pas d’envoi en double.
